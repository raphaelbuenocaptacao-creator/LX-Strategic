# LX Strategic

Plataforma inicial de planejamento estratégico, desenvolvimento de lideranças, salas e profissionais.

## Abrir

Para publicar, acesse **Settings → Pages** neste repositório, selecione **Deploy from a branch**, branch **main**, pasta **/(root)** e clique em Save. A página prevista, após habilitar o GitHub Pages, é:

https://raphaelbuenocaptacao-creator.github.io/LX-Strategic/

## Recursos

- Painel geral de salas, equipe, lideranças e metas.
- Salas de exemplo: DREAMS HOUSE (ativa) e SALA ROMANTIC (planejada). Horários iniciais são ilustrativos e editáveis.
- Cadastro, edição e exclusão de salas e profissionais; horários individuais e associação à sala.
- Cadastro de objetivos, status, datas e vínculos às salas.
- Mapa estratégico em SVG com nós clicáveis.
- Importação/exportação de backup JSON.

## Limites da versão 1

Os dados são armazenados por navegador em localStorage, não no GitHub. Não há sincronização entre celulares, controle de acesso ou banco de dados. Não cadastre dados sensíveis ou que exijam confidencialidade antes da autenticação e banco de dados. Recomenda-se backup manual.

## Verificação

Confirmar no navegador: criar/editar/excluir sala; criar/editar/excluir profissional; filtros; objetivos; mapa; exportar/importar; responsividade. A inclusão do código no repositório não equivale à validação completa em navegador.
